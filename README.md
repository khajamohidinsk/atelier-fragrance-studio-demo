# Atelier — Fragrance Studio Demo

A responsive, standalone fragrance-discovery UI built with vanilla HTML, CSS, and JavaScript. No build step or dependencies.

## Features
- Responsive desktop/mobile dashboard
- Search by fragrance, brand, mood, family, or note
- Mood filters and note-based discovery
- Fragrance detail dialogs, save buttons, and journal entry interaction

## Run
Open `index.html` in a browser. Or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Safety
All fragrance names, brands, descriptions, and ratings are fictional demo data. This project is independent of Ravenn and contains no proprietary source code, real product data, credentials, API keys, or private assets.
